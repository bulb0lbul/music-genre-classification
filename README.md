# Music Genre Classification

Определение музыкального жанра по мел-спектрограмме аудиозаписи.

## Текущее состояние

Подготовлены загрузка датасета, обработка метаданных, проверка аудио и анализ результатов. Из 8 000 записей FMA small оставлено 7 944. Аудио хранится только в исходных MP3. При загрузке запись переводится в моно, приводится к 44 100 Гц и обрезается с начала до минимальной длины: 1 321 438 отсчётов, примерно 29,96458 с. Промежуточные WAV не создаются. Исходные частоты, каналы и факт ресемплинга сохраняются в таблицах.

## Датасет

Используется **FMA small**: 8 000 фрагментов примерно по 30 секунд, 8 жанров. Архив аудио занимает около 7,2 GiB, метаданных — 342 MiB.

Описание и ссылки на скачивание: [официальный репозиторий FMA](https://github.com/mdeff/fma#data). Нужны `fma_small.zip` и `fma_metadata.zip`.

## Установка

Проверено на Python 3.12 и macOS с Apple Silicon.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

Для следующих запусков достаточно активировать существующее окружение:

```bash
source .venv/bin/activate
```

## Порядок запуска

Весь процесс одной командой:

```bash
python3 run_pipeline.py
```

Скачанные аудио и метаданные используются повторно, недостающие части скачиваются автоматически. Далее последовательно выполняются восемь этапов: подготовка метаданных, проверка аудио, перевод в моно, приведение к 44 100 Гц, подготовка фрагментов минимальной длины с обрезкой при загрузке, проверка примеров с подготовкой прослушивания, анализ результатов и построение всех графиков. При ошибке процесс останавливается. Таблицы и отчёты обновляются при каждом запуске; аудио обрабатывается в памяти при чтении исходных MP3. В общем запуске графики строятся один раз в конце. При отдельном запуске этапов их графики создаются автоматически; отключить их можно флагом `--no-plots`.

Отдельные этапы:

```bash
python3 download_data.py
python3 prepare_data.py
python3 validate_audio.py
python3 process_audio.py --all
python3 resample_audio.py
python3 trim_audio.py
python3 check_audio.py
python3 analyze_data.py
python3 plot_data.py
```

Если данные уже скачаны, первую команду можно пропустить. Для отдельной загрузки: `python3 download_data.py --only metadata` или `python3 download_data.py --only audio`.

## Файлы проекта

| Файл              | Назначение                                                                                                                               |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `run_pipeline.py`   | Общий запуск с загрузкой недостающих данных                                                                  |
| `download_data.py`  | Скачивание и распаковка аудио и метаданных                                                                    |
| `prepare_data.py`   | Выбор FMA small, метки жанров, пути к файлам и выборки                                                          |
| `validate_audio.py` | Чтение аудио, исключение ошибок и точных дубликатов                                                    |
| `process_audio.py`  | Сведение в моно при загрузке и подготовка таблицы                                                        |
| `resample_audio.py` | Ресемплинг при загрузке до 44 100 Гц с сохранением исходных частот                              |
| `trim_audio.py`     | Подготовка таблицы и чтение фрагментов с начала до минимального числа отсчётов |
| `check_audio.py`    | Проверка обработки примеров, таблица параметров и HTML для прослушивания                |
| `plot_data.py`      | Все графики проекта: метаданные, очистка, моно, жанры, ресемплинг и обрезка           |
| `analyze_data.py`   | Основные проверки, статистика и обзорный график                                                           |
| `requirements.txt`  | Зависимости проекта                                                                                                              |
| `task.txt`          | Исходная тема проекта                                                                                                           |

Каждый самостоятельный этап обработки реализован в отдельном файле. Все функции построения графиков пока собраны в `plot_data.py`.

## Данные и результаты

```text
data/
├── fma_metadata/
├── fma_small/
└── processed/
reports/
└── data_analysis/
plots/
├── *.png
├── mono/
└── resampling/
```

`data/processed/tracks_clean.csv` — записи для дальнейшей обработки. `tracks_excluded.csv` содержит причины исключения, `duplicates.csv` — найденные совпадения, `audio_summary.json` — итоги проверки аудио.

Анализатор выводит результаты в терминал и сохраняет их в `reports/data_analysis/`: `checks.csv`, `analysis_summary.json`, таблицы распределений. Обзорный график сохраняется в `plots/overview.png`.
