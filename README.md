# Music Genre Classification

Учебный проект на Python: определение музыкального жанра по мел-спектрограмме аудиозаписи. Планируется обучение CNN на PyTorch.

## Текущее состояние

Подготовлены загрузка датасета, обработка метаданных, проверка аудио и анализ результатов. Из 8 000 записей FMA small оставлено 7 944.

## Датасет

Используется **FMA small**: 8 000 фрагментов примерно по 30 секунд, 8 жанров. Архив аудио занимает около 7,2 GiB, метаданных — 342 MiB.

Описание и ссылки на скачивание: [официальный репозиторий FMA](https://github.com/mdeff/fma#data). Нужны `fma_small.zip` и `fma_metadata.zip`.

## Установка

Проверено на Python 3.12 и macOS с Apple Silicon.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

Для следующих запусков достаточно активировать существующее окружение:

```bash
source .venv/bin/activate
```

## Порядок запуска

Весь процесс одной командой:

```bash
python3 run_pipeline.py
```

Скачанные аудио и метаданные используются повторно, недостающие части скачиваются автоматически. Далее выполняются подготовка, проверка аудио и анализ. При ошибке процесс останавливается. Результаты обработки пересчитываются при каждом запуске.

Отдельные этапы:

```bash
python3 download_data.py
python3 prepare_data.py
python3 validate_audio.py
python3 analyze_data.py
```

Если данные уже скачаны, первую команду можно пропустить. Для отдельной загрузки: `python3 download_data.py --only metadata` или `python3 download_data.py --only audio`.

## Файлы проекта

| Файл              | Назначение                                                                            |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| `run_pipeline.py` | Общий запуск с загрузкой недостающих данных |
| `download_data.py`  | Скачивание и распаковка аудио и метаданных                 |
| `prepare_data.py`   | Выбор FMA small, метки жанров, пути к файлам и выборки       |
| `validate_audio.py` | Чтение аудио, исключение ошибок и точных дубликатов |
| `analyze_data.py`   | Основные проверки, статистика и обзорный график        |
| `requirements.txt`  | Зависимости проекта                                                           |
| `task.txt`          | Исходная тема проекта                                                        |

Каждый самостоятельный этап реализован в отдельном файле.

## Данные и результаты

```text
data/
├── fma_metadata/
├── fma_small/
└── processed/
reports/
└── data_analysis/
```

`data/processed/tracks_clean.csv` — записи для дальнейшей обработки. `tracks_excluded.csv` содержит причины исключения, `duplicates.csv` — найденные совпадения, `audio_summary.json` — итоги проверки аудио.

Анализатор выводит результаты в терминал и сохраняет их в `reports/data_analysis/`: `checks.csv`, `analysis_summary.json`, таблицы распределений и график `overview.png`.
